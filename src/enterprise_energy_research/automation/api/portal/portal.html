依赖与部署

依赖：Docker Desktop（唯一必需）＋ DeepSeek API Key（真实抽取）＋ 可选飞书应用（通知）/ Kimi WebBridge（深度调研）。Python 无需安装。

部署：复制 .env.example 为 .env 并填入密钥 → docker compose up -d --build → 打开本页。企业研究只在本页点击「开始调查」后运行；n8n 仅保留每日情报 10:00（北京时间）和纯故障看门狗。看门狗不会发起研究；日报可在本页暂停或恢复。
